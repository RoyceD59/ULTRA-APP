## Verification and limits

- `cd artifacts/uc-companion && pnpm exec tsc --noEmit`: passed.
- `cd artifacts/uc-companion && pnpm test`: passed, 557 tests, including seven new public-accessibility regression tests.
- Renderer tests use installed React Native Web and React DOM server rendering, not the native hook-test stubs. They establish emitted semantics, not a full browser accessibility-tree or screen-reader audit.
- Preview initially showed a blank page during Metro startup; the warmed About route rendered successfully at 402 × 874. Impact data showed its existing unavailable state because the preview API service was not running. No authentication bypass was introduced.
- Production keyboard, focus-order, screen-reader, native-phone, protected-flow and complete computed-style contrast audits were not performed. Source assertions for conditional fields do not claim those flows were submitted or verified end-to-end.
- Decorative `PhotoHeader` behavior and the already-semantic blog article headings are unchanged. Document language is tracked separately in technical SEO. No native-only maps or private/admin screens were added to the public audit.
