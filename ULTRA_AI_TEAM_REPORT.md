## 1. SYSTEM OVERVIEW

Ultra-AI-Team is a three-tier platform for the **Ultra Clear (UCFilters)** water-filtration business. It consists of:

| Artifact | Kind | Purpose |
|---|---|---|
| **API Server** | Node/Express REST | Central backend for all data, payments, notifications, AI, and media |
| **ProjectHub** | React Web App | Internal team operations dashboard |
| **Ultra-Clear Companion** | Expo React Native Mobile App | Customer-facing mobile shop & support |
| **Canvas / Mockup Sandbox** | Vite dev server | UI prototyping (internal, not user-facing) |

All three artifacts share a single PostgreSQL database via the `@workspace/db` package and communicate through typed REST contracts generated by `@workspace/api-zod`.

## 6. SECURITY & DATA PROTECTION AUDIT

### ✅ Implemented Security Controls
| Control | Implementation |
|---|---|
| Authentication | JWT (HS256), stored in localStorage; 401 auto-redirect |
| Admin boundary | `requireAdmin` middleware on all admin routes |
| Webhook integrity | Paystack HMAC-SHA512; M-Pesa bearer token; ProjectHub signed secret |
| Password storage | bcryptjs hashing |
| Upload ACL | ACL policy checked at presigned URL issue time; files served under UUID path |
| CORS | Configured on all routes |
| WhatsApp session | Stored in private Object Storage bucket (not public URL) |
| Dependency CVEs | pnpm overrides for `brace-expansion`, `js-yaml`, `fast-uri`, `postcss`, `fast-xml-parser` (Aug 2026) |

### ⚠️ Security Gaps & Recommendations

| # | Issue | Severity | Recommendation |
|---|---|---|---|
| S-1 | JWT in `localStorage` is readable by any JS on the page (XSS risk) | Medium | Migrate to `httpOnly` cookie with `SameSite=Strict`; keep short expiry |
| S-2 | `alison_admin_token` is a separate credential stored in localStorage with no expiry mechanism visible | Medium | Unify under main team auth; eliminate second token |
| S-3 | WhatsApp QR code page URL (`qrPageUrl`) — if publicly reachable, anyone can see the QR | High | Require team auth on QR page endpoint |
| S-4 | Upload presigned URLs: no MIME-type enforcement at the API boundary (only metadata check) | Medium | Validate accepted MIME types server-side before issuing presigned URL |
| S-5 | No rate limiting on auth endpoints (`/api/auth/login`, `/api/auth/register`) | High | Add express-rate-limit on auth routes (e.g. 10 req/min per IP) |
| S-6 | No rate limiting on payment initiation endpoints | Medium | Limit STK/Paystack/Stripe initiation per customer per minute |
| S-7 | `UC_ADMIN_EMAILS` env var not set → alerts silently skipped (no visible warning to admin) | Low | Add startup health check that warns visibly in ProjectHub System Status |
| S-8 | AI chat sends full message history to Anthropic — no PII scrubbing | Low-Medium | Add pre-send PII filter (phone/email regex strip) before forwarding to LLM |
| S-9 | MPESA_WEBHOOK_SECRET managed only via env var restart (task #126 pending) | Medium | Admin panel secret rotation without restart |
| S-10 | No Content-Security-Policy header on API responses | Low | Add CSP + X-Frame-Options + HSTS headers globally |

|---|---|---|
