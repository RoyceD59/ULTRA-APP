# Water loader artwork provenance
Sources: assets/loading/source/companion-water-loader.svg and -static.svg (uploaded; the SVG has no native animation despite its usage note). scripts/generate-filter-loader.mjs rasterises one falling drop plus two expanding ripples (motion from the HTML reference, 15 frames x 100 ms = 1.5 s) into assets/loading/water.webp and water-still.png (96x112, transparent). The still uses the supplied static SVG. Expo Image plays the lossless animated WebP, preserving full-alpha gradients and waves; the GIF derivative is retained for compatibility checks only. Regenerate: `node scripts/generate-filter-loader.mjs` (needs ImageMagick).
