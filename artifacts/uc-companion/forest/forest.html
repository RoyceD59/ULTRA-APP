The Hydrate the Future™ forest programme

Through Hydrate the Future™, 3% of eligible Ultra Clear sales revenue is allocated to the programme: half is allocated to tree growing and restoration in Kenya, half supports clean-water access. Customer contributions are pooled, so several customers contribute to each tree.

      How a tree grows

        Fully allocated is not the same as established. A fully allocated tree means contributions have reached its estimated cost. An established tree is one the programme has confirmed in the field. Only programme reports move trees to established.

        Methodology

        For every eligible transaction (a paid KES purchase that was not cancelled, failed or refunded):

        • allocation = eligible revenue × 3%
        • tree allocation = allocation × 50% (the other 50% supports clean-water access)
        • shared tree progress = tree allocations assigned to the tree ÷ tree cost
        • estimated trees funded = total tree allocation ÷ tree cost

        Tree allocations fill shared trees in purchase order, so several customers contribute to each tree together. Customers see their own allocation and their tree’s progress; who else contributes to a tree is never shown. Refills logged in the Companion app water a tree but carry no revenue, so they never add funding. Watering moves a tree from Seed to Sprout; funding progress moves it from Sapling onward.

        Links to this page carry only an anonymous tree id and a growth stage, never names, contact details, amounts or percentages.
