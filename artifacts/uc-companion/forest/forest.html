Through Hydrate the Future™, 3% of eligible Ultra Clear purchases is allocated to the programme: half grows and restores trees in Kenya, half supports clean-water access. Customers’ contributions combine, so several people grow each tree together.

How a tree grows

    Funded is not the same as established. A funded tree means contributions have reached its estimated cost. An established tree is one the programme has confirmed in the field. Only programme reports move trees to established.

    Methodology

    For every eligible transaction (a paid KES purchase that was not cancelled, failed or refunded):

    • allocation = eligible revenue × 3%
    • tree share = allocation × 50% (the other 50% supports clean-water access)
    • shared tree progress = tree shares assigned to the tree ÷ tree cost
    • estimated trees funded = total tree share ÷ tree cost

    Tree shares fill shared trees in purchase order, so several customers grow each tree together. Customers see their own share and their tree’s progress; who else funds a tree is never shown. Refills logged in the Companion app water a tree but carry no revenue, so they never add funding. Links to this page carry only an anonymous tree id and a growth stage, never names, contact details, amounts or percentages.
